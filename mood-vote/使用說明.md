# 心情投票・使用說明

親和活動暖場用。學員用手機掃 QR code、點一下就完成，台前大螢幕的長條圖會即時長高。
**不記名、不需要登入、不收任何個人資料。**

## 檔案一覽

| 檔案 | 用途 |
|---|---|
| `index.html` | **學員頁**：手機打開、點選心情 |
| `screen.html` | **展示頁**：投影到大螢幕，顯示長條圖與 QR code |
| `config.js` | **唯一需要改的檔案**：題目、選項、Firebase 設定 |
| `store.js`、`qrcode.js` | 程式本體，不用動 |
| `firestore.rules`、`firebase.json`、`.firebaserc` | Firebase 安全規則（只接受「選了第幾個」，其他資料一律擋掉） |

## 一、先試看（不用 Firebase）

`config.js` 裡的 Firebase 設定還是空的時，會自動進入「試看模式」：

1. 在電腦上同時打開 `screen.html` 和 `index.html` 兩個分頁
2. 在 `index.html` 點一個心情，回到 `screen.html` 就會看到長條圖變化
3. 展示頁右下角有「模擬 10 人投票」，可以看多人投票時的樣子

> 試看模式只有同一台電腦會同步，手機投票不會出現在大螢幕上。

## 二、正式使用（接上 Firebase）

在 Claude Code 跟它說：

> 「照 `04.5-連接-Firebase-資料庫.md` 幫我建好 Firebase，然後把設定填進 `mood-vote/config.js`，再部署 `mood-vote/firestore.rules`。」

完成後把整個 `mood-vote` 資料夾放上網（例如 GitHub Pages），網址會像：
`https://你的帳號.github.io/專案名稱/mood-vote/screen.html`

> ⚠️ 如果你的 Firebase 專案已經有其他工具的規則，請把 `firestore.rules` 裡 `moodRooms` 那一段**合併**進原本的規則檔，不要整份覆蓋，以免其他工具壞掉。

## 三、活動當天怎麼用

1. 大螢幕打開 `screen.html`，按右下角「全螢幕」
2. 請大家用手機相機掃 QR code
3. 想看前後心情變化？活動開始時投一次，結束前按「**重新開始**」再投一次
4. 要專心講話時，可以按「隱藏 QR code」，讓長條圖佔滿畫面

右下角的按鈕平常是半透明的，滑鼠移過去才會清楚，不會干擾畫面。

## 四、同時辦好幾場？

在網址後面加上 `?r=場次名稱`（英文或數字），每一場的票數就會分開計算，例如：

- 展示頁：`screen.html?r=taipei1027`
- QR code 會自動帶上同一個場次，學員不用自己輸入

## 五、改題目或選項

打開 `config.js`，直接改中文字就好：

- `question`：題目
- `options`：選項（最多 6 個），每個有圖示、名稱、小字說明、顏色
- `thanks`：學員送出後看到的話

## 活動前檢查清單

- [ ] 用自己的手機實際掃一次、投一次，確認大螢幕有變化
- [ ] 確認現場網路：最好請大家用**手機自己的網路**，不要全擠場地 Wi-Fi
- [ ] 準備備案：萬一網路不通，改成「舉手投票」，活動照樣進行
- [ ] 正式開始前按一次「重新開始」，清掉測試的票

## 已知限制

- 「重新開始」按鈕沒有密碼保護，知道展示頁網址的人都能按。親和活動通常沒問題，但不要把展示頁網址公開貼出去。
- 同一支手機只算一票（可以改選）；換瀏覽器或用無痕模式，可能會被算成另一票。
